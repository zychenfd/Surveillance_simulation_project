# xml file templates and examples

## Note
- Template for phylogenetic analyses: BEAST1_tree_template.xml (example: seq_homo_sim100_1.xml)
- Template for phylogeographic analyses: BEAST1_geo_template.xml (example: seq_homo_sim100_1_spa.xml)
- Template for travel history-informed phylogeographic analyses: BEAST1_geotravel_template.xml (A tutorial on using travel history in phylogeographic analysis is available at DOI: 10.1002/cpz1.98) (example: seq_homo_sim100_1_spatravel.xml)
- Template for joint phylogenetic and phylogeographic analyses under a structured coalescent approximation framewrok: BIT_ScaExpPerDemeSameRate_template.xml
